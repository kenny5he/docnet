# 探索性数据分析 EDA(Exploratory Data Analysis)
1. EDA核心目标
    1. 发现数据中潜在规律与模式
    2. 识别异常值并检验初步假设
    3. 为建模阶段提供直观洞察支持
2. 分析工具与方法
    1. 可视化：利用直方图、散点图观察分布
    2. 汇总统计：均值、标准差初步摸底数据
    3. 趋势识别：评估特征间的相关性
3. 模型构建：寻找简化的规律
    1. 定义显示过程的简化数学表示
    2. 核心目的：
        1. 推断： 理解变量间的内在联系
        2. 预测：基于历史规律估计未来
    3. 组成要素
        1. 特征：输入变量X
        2. 目标：预测输出Y
    4. 模型构建过程：
        1. 算法选择(选择回归、分类、聚类等算法)
        2. 训练验证(拟合历史数据、评估预测准确性)
        3. 参数优化(调整超参数、提升模型泛化力)
