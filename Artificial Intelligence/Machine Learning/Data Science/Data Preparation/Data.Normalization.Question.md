# 数据标准化(Normalization)
## 识别和处理缺失数据
1. 缺失值：数据集中某些属性值未记录或未采集到的情况
2. 表现形式：
    - SQL/数据库: NULL
    - Python/科学计算: NaN，N/A
    - 文档/表格: 空白(Blank)
3. 影响：
    - 降低样本代表性: 扭曲数据分布，导致分析偏差
    - 导致运行错误：多数机器学习算法无法直接计算含空值的项
    - 破坏数据完整性：引发ETL流程中断或逻辑判断失效
4. 检测缺失数据的方法
    1. 使用统计函数扫描
        - 快速扫描各字段(Field)缺失计数
        - 定位缺失率较高的特征维度
    2. 检查记录完整性
        - 识别全行缺失的无效数据行
        - 评估单条业务记录的数据质量
5. 可视化缺失数据模式
    1. 热图可视化(Heartmap)
        - 快速识别数据矩阵中的大片缺失区域
    2. 缺失条形图(Bar Chart)
        - 直观对比不同特征的缺失严重程度
    3. 缺失矩阵图(Matrix Plot)
        - 多特征关联，寻找缺失值的分布规律(例：某个字段与其它缺失字段的联系)
6. 处理缺失数据的方法
    1. 原则：遵循GIGO原则，根据数据分布特征性选择最合适方法
    2. 删除法
        - 应用条件：
            1. 缺失比例极高，缺失率高于5%
            2. 目标列(Target)缺失，特征列极度重要
        - 处理方式：行删除/列删除
        - 目的：减少偏见风险
    3. 基础填充
        - 均值填充 (数值)
        - 中位数填充 (数值)
        - 众数填充 (分类数据)
    4. 时序填充
        - 处理方式
          - 向前填充(ffill)
          - 后向填充(bfill)
          - 时间序列专用
        - 场景：股价、气温
    5. 高级插值
        - 相关性预测
        - 回归分析填充
        - 复杂场景应用
## 处理重复数据 (Duplicate Data)
1. 重复数据：数据集中存在两条或多条完全相同或高度相似的记录
2. 重复场景
    1. 完全重复(Complete Duplicates): 全列数据完全一致
    2. 特定重复(Specific Duplicates): 关键主键相同
    3. 非完全重复(变体重复)
        - 拼写变体: 如 "IPhone17" 与 "IPhone 17"
        - 输入误差: 缩写、多余空格、字符差异等
3. 目的：
    1. 防止统计偏见: 避免平均值或总计数被虚假夸大
    2. 优化系统资源: 节省不必要的计算或存储空间
    3. 提升模型性能: 防止AI模型过度拟合特定噪声模式
4. 识别重复行
    1. 全匹配逻辑：
        - 在检测过程中，系统会对比每一行中所有列的值，当且仅当所有字段数据完全相等
    2. 特定识别重复项
        - 关键列选取：身份证、手机号、邮箱、主键
        - 处理方案： 1. 保留最新记录  2. 多维属性合并
5. 处理策略
    1. 注：对于大规模数据集，建议优先通过subset确定唯一性约束，遵循GIGO原则确保数据质量
    2. 保留策略
        - 默认 keep='first'
        - keep='last'保留末尾
        - keep=False 全部剔除
    3. 制定列集
        - subset 参数指定范围
        - 聚集业务关键字段
        - 降低对比计算开销
    4. 序列重排
        - 去重后参数索引物理空洞
        - 推荐 ignore_index=True
        - 保证行号连续递增
## 修复数据类型
1. 核心目标：将非标准原始数据转换为机器可理解的确定类型
2. 场景：
    1. 伪装数字: 带有货币符号或都好的文本
    2. 日期混杂: YYYY-MM-DD 与 DD/MM 混存
    3. 非法空值: 数值列中包含 "None" 或 ""
3. 转换范畴: 数值标准化、日期解析与分类标签化
4. 容错处理: 针对无法解析的 "脏数据"制定补全或剔除策略
5. 识别不正确的数据类型
    1. 描述性统计: 检查均值、最值是否异常
    2. 概览函数: 使用 .info() 或 .describe()
## 数据格式化、标准化
1. 统一大小写与去空格: 将分类标签转为全小/大写
2. 去除空格: 删除首尾不可见的 "隐身"字符
3. 自动化处理: 使用trim(SQL)/strip(Python)高效批处理
4. 字符串批量替换
5. 统一度量衡单位
6. 核心方法: 构建统一标准映射库(Mapping Library)
