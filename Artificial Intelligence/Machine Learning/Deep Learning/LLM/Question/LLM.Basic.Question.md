# 大模型基础原理
1. 大模型结构：
    1. 输入层: 接收原始文本输入
    2. 分词器(Tokenizer)：将输入文本分割成词或子词，以便模型处理
    3. Transformer 编码器(Encoder): 对输入的词进行编码，生成词的向量表示
    4. Transformer 解码器(Decoder): 基于编码器的输出，预测下一个词
    5. 输出层：生成最终的文本输出
2. LLM带参数层主要类型:
    1. embedding层: 将每个Token转换为语义+位置embedding向量
    2. Transformer层:
        1. Q/K/V矩阵，捕捉上下文关系，自注意力机制核心
        2. MLP层，细化捕捉局部关系，与自注意力机制互补，知识存储核心
        3. 残差旁路层矩阵，短路处理简单语义
    3. 输出投影层： 前序embedding投影成token概率矩阵，用于下一个词采样
3. 过程: 
    1. (分词)输入文本转成embedding
        > 根据分词器分词(离散词表+分词规则)， 
        > 分词onehot转为词自身语义+位置的初始embedding
    2. (注意力/上下文关系)从初始embedding提取上下文语义embedding:
        > 自注意力机制捕捉上下文关系，得到注意力值；
        > 1) 残差旁路短接简单层语义
        > 2) Q与K转置进行矩阵乘，捕捉上下文关系，归一化后与V矩阵乘，得到注意力值，作为下一层transformer的输入
        > 3) 不断叠加transformer层的计算，得到上下文语义embedding
    3. (概率)从上下文语义embedding聚合成输出概率值:
        > 线性层+softmax将前T个token embedding聚合，获得第T个Token在整个词表的概率值；
        > 根据采样策略(贪心/beam search等)，选取高概率token作为next token
4. 特点
    1. 单向思考模型: 每次只根据前面内容预测下一个词
    2. 层层解码设计: 内部由多个"理解层"串联，每层专注不同细节(首层认单词，深层懂逻辑/情感)
    3. 数据炼成直觉: 喂海量文本(书籍/网页)，让模型自己总结语言规则，而非人工编程
    4. 规模创造智能: 层数+数据量足够大，突然涌现"类人能力" --写故事、写诗、答问题、编写代码...
5. 位置编码(正余弦位置编码)
    1. 公式: 
        - $PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right), \quad$
        - $PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right)$
    2. 公式解释:
        - base: 作为分母的base值(如式子中的10000)，应大于模型支持的最大上下文长度
        - pos: token的序号
        - $d_{\text{model}}$: 与模型相关的向量长度大小
        - i: 向量中的元素序号索引，范围[0, $d_{\text{model}}$], $d_{\text{model}}$是与模型相关的向量长度大小
6. 两大模型结构(FFN层): 稠密和稀疏(MoE)
    1. 稠密模型: 采用传统神经网络架构，其所有参数在每次前向传播中都会被激活和使用，也就是说，无论输入是什么，整个网络每一层都会参与计算
    2. MoE模型: MoE模型将网络中的某些层替换为多个“专家”子网络，并通过“门控网络”(gating network)动态决定对每个输入激活哪些专家，通常每次只激活少数几个专家，因此属于稀疏激活模型。

    | 维度     | 稠密模型        | MoE模型               |   
    |----------|-----------------|-----------------------|
    | 激活方式 | 全部参数激活    | 稀疏激活(仅部分专家)  |
    | 计算效率 | 较低            | 更高                  |
    | 推理成本 | 高              | 低一个量级            |
    | 显存占用 | 相对较低        | 高(需加载所有专家)    |
    | 模型扩展 | 受限于计算资源  | 易扩展，适合超大模型  |
