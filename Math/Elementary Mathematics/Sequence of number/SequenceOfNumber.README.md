# 数列

## 斐波那契数列 = 黄金分割数列 (Fibonacci sequence)
1. 从第3项开始，每一项都等于前两项之和
2. 公式: $ F(0)=0，F(1)=1, F(n)=F(n - 1)+F(n - 2)（n ≥ 2，n ∈ N*）$
3. 案例
    1. 兔子问题
    2. 爬楼梯问题 (Climbing Stairs): 
        - Q: 小明的教室在教学楼5楼，教学楼每层有10级阶梯，爬楼梯回教室(一次最少爬一级，最多爬两级)，爬1级楼梯，方法只有一种，爬2级楼梯，方法有两种，爬3级，方法有3种，请问小明回到5层教室，可以有多少种爬法？
        - 重点: 最后一步爬1级 为前一次爬的方法数，最后一步爬2级 为前两次爬的方法数，即 $ F(n)=F(n - 1)+F(n - 2) $
