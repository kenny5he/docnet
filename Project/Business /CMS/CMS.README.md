# 内容管理系统 (Content Management System)

## 内容分组
1. 文章心得
    1. 文章主体
    2. 附件
    3. 点赞、收藏、转发
    4. 文章评论
2. 发帖求助问答
    1. 问题分类
        1. 系统模块
        2. 阶段(生命周期)
        3. 材质
        4. ...
    2. 求助帖: 点赞、收藏、转发
    3. 评论: 点赞、评论、采纳
3. 知识库(Wiki) 
    1. 目录
    2. 文章
        1. 文章类别(富文本、Markdown)
        2. 文章目录
    3. 内容标记(引用：评论)
